# GigPies

**Mix the band. Run the lights. Keep control.**

A live-band system for Raspberry Pi: audio and lighting desks, performer monitors,
PA processing, effects and multitrack recording. Manual control comes first;
assistance and automation are optional.

[![GigPies audio desk — Channel EQ, compression and metering](https://raw.githubusercontent.com/gigpies/gigpies/main/docs/assets/panel-desk-channel.png)](https://github.com/gigpies/gigpies)

Actual terminal capture with software audio. The system is experimental;
full live hardware qualification and physical DMX output remain unfinished.
