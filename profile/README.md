# GigPies

![GigPies — audio and lighting terminal desks at a live-band stage](https://raw.githubusercontent.com/gigpies/gigpies/main/docs/assets/gigpies-hero.png)

*Concept artwork of the intended setup.*

**Mix the band. Run the lights. Keep control.**

**Terminal applications (TUIs) for live-band sound and lighting on Raspberry Pi.**
Audio and lighting desks, performer monitors,
PA processing, effects and multitrack recording. Manual control comes first;
assistance and automation are optional.

The system is experimental; full live hardware qualification and physical DMX
output remain unfinished. [See the actual Channel TUI](https://github.com/gigpies/gigpies#channel-view--running-in-a-terminal).

[**Start here**](https://github.com/gigpies/gigpies) · [**Using GigPies**](https://github.com/gigpies/gigpies/blob/main/docs/README.md) · [**What works today**](https://github.com/gigpies/gigpies/blob/main/docs/STATUS.md)
