# Help and feedback

Start with [Using GigPies](https://github.com/gigpies/gigpies/blob/main/docs/README.md).
For bugs or ideas, open an issue in the affected module. If ownership is unclear,
use [GigPies issues](https://github.com/gigpies/gigpies/issues).

Include the version, what you tried and what happened. For display problems,
include the terminal, window dimensions and a screenshot. Remove private settings
and credentials from logs. No commercial support or response deadline is promised.
